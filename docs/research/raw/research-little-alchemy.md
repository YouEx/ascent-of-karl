# Little Alchemy recipe research

Full recipe dumps extracted from reverse-engineered game data in the
`redfast00/element-alchemy-cheater` GitHub repository (`JSONrecipes/`), which
contains recipes decompiled from the official apps. Duplicates removed
(unordered ingredient pairs), sorted by result. Format: `a + b = result`.
